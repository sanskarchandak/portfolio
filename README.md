# 🌐 Personal Portfolio Website

A responsive personal portfolio website showcasing my professional experience, technical skills, and projects as a Software Test Engineer.

**Version:** v1.0  
**Status:** Active Development 🚀

---

## 📌 Overview

This portfolio serves as my personal website and is built using vanilla web technologies. It is also being used as a hands-on project to learn and demonstrate:

- Git & GitHub
- CI/CD with GitHub Actions
- Automated Deployment
- Frontend Testing
- Playwright Automation
- Software Engineering Best Practices

---

## ✨ Features

- Responsive Design
- Modern UI with Bootstrap 5
- Animated Sections
- Resume Download
- Contact Section
- Smooth Scrolling Navigation
- Mobile Friendly

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
