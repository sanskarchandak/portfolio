Test Automation & CI/CD

A real-world QA automation project where this portfolio website is the application under test. The workflow combines Selenium, TestNG, Maven, Jenkins and GitHub Actions to validate changes before deployment.

About the Project

Instead of building a separate demo application, I use my own portfolio website as the application under test. The automation framework validates important user journeys while Jenkins controls the CI pipeline.

The project demonstrates UI automation, test organization, CI execution, deployment gating and automated hosting as one connected QA workflow.

How It Works

01. Code change Changes are committed to the GitHub main branch.
02. Jenkins pipeline Jenkins checks out the repository and executes the Jenkinsfile.
03. Smoke testing Maven runs the TestNG tests group against the website.
04. Quality gate A failed tests suite stops the pipeline before deployment.
05. GitHub Actions Jenkins triggers the deployment workflow through the GitHub API.
06. Production deployment GitHub Actions deploys the website to InfinityFree.
